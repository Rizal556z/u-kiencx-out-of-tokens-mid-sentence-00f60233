Entry for the make.fun bounty [Out of Tokens, Mid-Sentence](https://make.fun/bounty/u-kiencx-out-of-tokens-mid-sentence-00f60233): one funny error-message line an AI agent might show when it runs out of tokens mid-sentence. `main.py` writes that single line — at most 140 characters — to `/output/entry.txt`.

> ERROR: Out of tokens mid-sentence. The next word was going to be brilliant. You'll never know what it—

## Run it with: python3 main.py

```sh
python3 main.py
cat /output/entry.txt
```
